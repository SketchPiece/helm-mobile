Better than A

  • Every tool gets the full screen at once, no ⤢ step.
  • The terminal's input looks like the composer: one way to type on the phone.

Worse than A

  • A sideways swipe in the terminal output or a long line of code moves the page instead. Only an edge swipe is safe, and that's A again.
  • You can't see the thread while the terminal is open: «agent ran tests, let me check» means flipping back and forth.
  • A fixed row of pages doesn't fit «several terminals + open files». The desktop's tabs do.
  • The dots and pages are a new idea for the app; A reuses what the desktop panel already is.

Why A

A keeps a piece of the thread in view, uses one safe gesture, and maps 1:1 to the desktop panel's tabs, so state (which terminals, which files) can be shared with the Mac later.
