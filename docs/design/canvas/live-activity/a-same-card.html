States are glyphs, not words. Done is a green check in a circle, failed is a red cross, approval is a hand, a question is a speech bubble, working is a ring. The word stays only in the hero, where it explains what is wanted (1, 6).
Fixed timer slot, 48 pt, right-aligned, tabular digits. In Always On the seconds become «––» in the same place, so nothing moves (2). The timer counts from the run's start, not from the last event (3).
Fits in 160 pt: a one-line hero, at most 2 rows, and «+2 more» (4, 11).
Always On keeps the colours, slightly dimmed, and the glyphs tell states apart even without colour (5).
The hero says how long it has been waiting: the timer sits on the kicker line (12). The kicker is sentence case, not caps (10). Stale is one line in the header (9).
