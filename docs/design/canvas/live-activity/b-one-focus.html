One thing at a time. The card shows the most important thread big: a glyph in a tinted circle, the state and how long it has been in it, and the title. The rest is one line at the bottom: «2 working · 1 done».
Always fits in 160 pt however many threads there are. No list to cut off (4, 11).
The Dynamic Island goes the way Apple's Timer does: the state glyph on the left (instead of the logo) and the timer on the right in a fixed slot. The island never changes width while it ticks (7, 8). When everything is done it's a check with nothing on the right.
The cost: without opening the island you can't see the names of the other threads. If you usually run 3–4 agents at once, that's a loss.
The «Open» button in the expanded island is optional; tapping the island opens the thread anyway.
