One component

  • Tap, “+” and ⌘N open the same card. ⌘K’s “New thread in…” pushes into it too.
  • Rows 52pt with icon and path — a finger and a pointer both hit them; ~10 projects fit, the rest scroll.
  • No project and the current one on top, then all projects by last use.

Touch vs keyboard

  • Opened by a tap: the search field isn't focused, so the on-screen keyboard doesn't cover the list. Tap the field to type.
  • With a hardware keyboard: the field is focused, typing filters, ↑↓ ⏎ and ⌘1–9 work. The ⌘ numbers and the footer show only then.

Kept from the sheet

  • “+ Add” in the field row opens Add project; long-press / right-click a row: Edit, Delete.

iPhone

  • Keeps the sheet; this is for regular width.
