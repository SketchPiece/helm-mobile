⌘K: jump anywhere

  • Searches every thread on every Mac by title and project, then actions. One list, typed into without the mouse.
  • ⏎ opens in this window, ⌥⏎ in a new window (Stage Manager).
  • It's the search field from the sidebar, centered: same model as Home's search, plus actions.
  • Like the quick switchers in Slack, Linear and VS Code. ux-audit.md listed the command palette as later; on iPad it pays for itself.

Without a keyboard

A tap on «Search ⌘K» in the sidebar opens the same thing. On the phone nothing changes.
