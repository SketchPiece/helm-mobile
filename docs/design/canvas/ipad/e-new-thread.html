New thread

  • ⌘N from anywhere: a draft row appears at the top of the sidebar (today's DraftRow) and the new-thread screen opens on the right.
  • The composer card is centered and already open, with the cursor in it. With a hardware keyboard you can start typing straight away.
  • The project is the one selected in the chips (Волна here). Change it with the underlined name or ⌘↑.

With a hardware keyboard

  • ⏎ sends, ⇧⏎ adds a line. Without a keyboard, the iPhone behaviour stays (Return adds a line, the arrow sends).
  • The line of hints shows only while a keyboard is connected (GCKeyboard) and fades after the first send.
  • Tab moves focus to the chips instead of typing a tab. ⌘V pastes images as attachments.

Pointer

  • Chips and buttons get the system glass hover. Each menu opens on the first click (AGENTS.md: no interactive glass around menus).
