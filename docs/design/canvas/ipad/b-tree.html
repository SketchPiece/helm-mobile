What changes from A

  • The sidebar is grouped by project, as in Helm Desktop: folding groups, one line per thread.
  • Needs you stays at the top across projects, so an approval doesn't get lost inside a folded project.
  • + next to a project (on hover or long press) starts a thread in it.

For

  • The Mac and the iPad look alike, so the iPad works as a «second screen» for the desktop app.
  • Lots of threads in a few projects fit easily.

Against

  • Phone and iPad disagree: on the phone the list is by state, here by project. A compact window has to switch models.
  • One line per thread drops the branch and the Mac.

Could be a setting

«Group by project» in the sidebar's ⋯ menu, on top of A. Same List, a different grouping.
