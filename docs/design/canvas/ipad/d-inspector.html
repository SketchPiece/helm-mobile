Review changes: an inspector, not a sheet

  • «Review» on the changes card, the ± button in the toolbar or ⌥⌘I opens the diff beside the chat, so the agent's explanation and the code are both in view.
  • On an 11" the sidebar folds itself away while the inspector is open, and comes back when it closes (a change from resizing has to be reversible).
  • On a 13" all three fit: sidebar + chat + inspector.
  • In a compact window .inspector becomes today's ChangesSheet, with no extra code.

Inside

  • This turn / Whole branch, the file list, the diff (today's DiffViews).
  • «Ask about this diff» puts the selected file into the composer as a reference.
